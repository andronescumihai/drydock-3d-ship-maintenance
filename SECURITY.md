# Security

DryDock is a static, client-only web application: there is no backend, no
database, no user accounts and no personal data. The hardening that is in place
is described in the README under **Security**.

## Reporting a problem

If you find a security issue — for example a way to run script in the page, a
missing or ineffective header, or a vulnerable dependency — please open a
private report through GitHub's **Security → Report a vulnerability** on this
repository rather than a public issue. Include what you found, how to reproduce
it and what an attacker could do with it.

Reports are answered on a best-effort basis; this is a portfolio project, not a
commercial service.

## Scope

In scope: the application code in this repository and its deployed pages.
Out of scope: denial-of-service by heavy traffic, and findings that need a
compromised browser or device.
